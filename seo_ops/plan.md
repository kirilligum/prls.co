# SEO Ops Plan (Cloudflare-first)

## Purpose
Automate SEO monitoring and remediation for prls.co using Cloudflare Workers/Workflows/Queues, with API-first checks and browser automation only when necessary (e.g., GSC “Request indexing”). Keep full audit logs for debugging.

## Current Context (as of 2026-01-17)
- Production branch: `website-live` (Cloudflare Pages deploys from this branch).
- Canonical URL shape:
  - Company landing pages use `/company_id/` (page 1).
  - Deep pages use `/company_id/2+` (no `/company_id/1`).
  - Legacy `/*.html` AIK pages removed and redirected.
- Redirects (must remain):
  - `https://prls.co/*` → `https://www.prls.co/:splat`
  - `/*/*.html` → `/:splat`
  - `/*/*/` → `/:splat`
  - `/*/1` → `/:splat/`
- Sitemap is generated by `website/generate-sitemap.js` during build and submitted to GSC.
- GSC API exists for inspection + sitemap submission; “Request indexing” requires GUI automation.
- Repo hygiene:
  - `.gitignore` excludes `website/.astro/`, `website/.wrangler/`, `website/.dev.vars`, `website/dist/`, `website/node_modules/`.
  - Avoid committing large generated dumps (docs scrapes, temp files, backups) to production branch.

## Local Scripts (Phase 0)
Until automation is deployed, use local scripts:
- `seo_ops/scripts/inspect_gsc.fish` → API inspection + report.
- `seo_ops/scripts/request_indexing.fish` → GUI request indexing (Playwright).
- `seo_ops/scripts/recheck_gsc.fish` → inspect + request indexing where needed.
- `seo_ops/scripts/urls_priority.txt` → canonical URL list.

## Agents and Prompts

### 1) GSC Analyst Agent
**Goal:** Track index coverage and URL inspection changes.
**Inputs:** URL list, GSC property, threshold rules.
**Outputs:** Task entries + alert log.

**Prompt:**
```
You are the GSC Analyst. Using GSC API, gather:
- Pages report totals (indexed vs not indexed).
- URL inspection status for the priority list.
Flag regressions: duplicates, canonical mismatches, or “not indexed” status.
Create tasks for any issues and add evidence links.
```

### 2) Sitemap/Canonical Monitor Agent
**Goal:** Validate sitemap correctness and canonical patterns.
**Inputs:** Sitemap URL + canonical rules.
**Outputs:** Validation report + alerts.

**Prompt:**
```
You are the Sitemap/Canonical Monitor. Fetch sitemap.xml and validate:
- Only canonical URL shapes are present.
- No /company_id/1 URLs.
- No *.html URLs.
- All URLs are https://www.prls.co/.
Report violations and open tasks with exact URLs.
```

### 3) Redirect Verifier Agent
**Goal:** Ensure legacy URLs 301 to canonical URLs.
**Inputs:** Sample legacy URLs.
**Outputs:** Failures list + tasks.

**Prompt:**
```
You are the Redirect Verifier. Check a sample of:
- https://prls.co/*
- https://www.prls.co/{company}/1
- https://www.prls.co/{company}/{n}.html
- https://www.prls.co/{company}/{n}/
Confirm 301 → canonical. Log any non-301 or wrong targets.
```

### 4) Indexing Request Agent (GUI-only)
**Goal:** Submit “Request indexing” for priority URLs.
**Inputs:** URL list.
**Outputs:** D1 action logs + screenshots.

**Prompt:**
```
You are the Indexing Request Agent. Use Playwright (GUI) to open GSC,
inspect each URL, and click “Request indexing.”
Log each URL request with timestamp and status.
Do not use API (not supported for indexing requests).
```

### 5) Post-Deploy Auditor Agent
**Goal:** Validate critical SEO behavior after deploy.
**Prompt:**
```
You are the Post-Deploy Auditor. After deploy to website-live:
- Confirm sitemap generation succeeded.
- Inspect 3–5 URLs and validate canonical.
- Confirm redirects still work.
Open tasks for any regressions.
```

## Data Model (D1 sketch)
- **checks:** id, type, url, status, result, created_at
- **inspections:** url, inspection_status, coverage_state, canonical, last_crawled
- **actions:** action_type, url, payload, status, created_at
- **alerts:** severity, message, created_at, resolved_at

## Workflows (initial)

### Workflow: daily_gsc_health
1) Fetch sitemap and validate patterns.
2) Inspect priority URLs.
3) Compare indexed vs not indexed counts; if spike, create alert.

### Workflow: post_deploy_check
1) Run when Pages deploys on `website-live`.
2) Inspect priority URLs.
3) Resubmit sitemap if canonical changes detected.

### Workflow: request_indexing_batch (GUI)
1) Use Playwright / Browser Rendering.
2) Request indexing for URLs needing crawl.
3) Log results to D1 + R2 screenshot.
